Abstract

The IDE of mouse liver ST data generated using nanoString’s CosMx™ technology. The datasets are composed of single-cell gene expression counts from two separate sample slides, which are stored in two separate Seurat objects.

What Data Do We Have?

For this initial data exploration (IDE) we have spatial transcriptomics (ST) data generated from mouse model liver tissue. Tissue samples were taken from mice with different stages of alcoholic liver disease.

Following disease states are represented in the data:

  1. Healthy
  2. Steatosis
  3. Cirrhosis
  4. Acute-on-Chronic Liver Failure (ACLF)

Data Generation

The data was generated using nanoString’s CosMx™ spatial molecular imager (SMI). This assay provides transcriptomics data at cellular and subcellular resolutions using a non-damaging in situ approach. The samples were prepared and processed on two separate slides. Each slide led to an individual Seurat object, which stores the resulting expression counts and spatial information.

The CosMx™ Mouse Neuroscience Panel defined the set or genetic markers to be tracked. This leads to a certain “brain” bias.

Markers that were used to visualize the cell morphology:

B2M

Beta-2 Microglobulin, a small protein that is a component of MHC class I molecules found on all nucleated cells. It is often used as a marker in immunohistochemistry.

CD298 (SLC12A2)

Protein associated with ion transport and is often used as a marker for certain cellular functions.

PanCK

Pan-Cytokeratin, a group of cytoskeletal proteins found in epithelial cells. It is used to identify epithelial cell populations in tissue.

CD45

Marker for leukocytes (white blood cells). It is used to identify immune cells in tissues.

CK8/18

Cytokeratin 8/18, which are intermediate filament proteins expressed in epithelial cells, particularly in simple epithelia such as those of the liver.

DAPI

4′,6-diamidino-2-phenylindole, a fluorescent stain that binds strongly to DNA, commonly used for nuclear staining in microscopy.

Metadata columns that will be important for this project will be:

  1. Slide_name
  2. tissue
  3. fov

fov assigns each cell to its corresponding tissue “stamp”. A slide contains multiple tissue slices, with each slice being “stamped” n times. The fov value indicates in which stamp a given cell is located.

Add Metadata disease_state

Disease State Metadata

The disease state must be added to the existing Seurat object, as this data is not currently included in the meta.data table. The disease states are mapped via the FOV IDs.

The disease state mapping can be found in the corresponding code blocks.

# Disease state to FOV mapping
healthy <- c(1, 2, 15, 16, 17, 18, 19, 20, 21, 22, 23, 45)
cirrhosis <- c(5, 6, 24, 25, 26, 30, 31, 34, 35, 40, 41, 44)
steatosis <- c(3, 4, 9, 10, 13, 14, 27, 28, 29, 38, 39)
aclf <- c(7, 8, 11, 12, 32, 33, 36, 37, 42, 43)

# Add column "disease_state"
# Condition is assigned according to defined mapping
disease_states_l1 <- data.frame(
  fov = sobj_liver1@meta.data$fov, # Conditions are mapped to FOVs
  row.names = colnames(sobj_liver1)
) |>
  mutate(
    disease_state = case_when(
      fov %in% healthy ~ "healthy",
      fov %in% cirrhosis ~ "cirrhosis",
      fov %in% steatosis ~ "steatosis",
      fov %in% aclf ~ "aclf",
      TRUE ~ "Other"
    )
  ) |>
  select(-fov)

# Add disease condition to metadata
sobj_liver1 <- AddMetaData(
  sobj_liver1,
  metadata = disease_states_l1
)

# Validate that correct disease states are added.
if (identical(
  unique(disease_states_l1)$disease_state,
  unique(sobj_liver1@meta.data$disease_state)
)) {
  message("Metadata added correctly to Liver 1.")
