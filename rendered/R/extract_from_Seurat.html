Abstract

Extract the relevant data from the merged liver Seurat object to prepare it for conversion into an AnnData object in Python. This includes the expression matrix as well as metadata such as condition, field of view (FOV), and other relevant annotations.

Counts

To efficiently store the counts in their sparse representation, they are saved in the Matrix Market (MM) format. The data is stored in an .mtx file using the coordinate format, where only non-zero values are stored along with their respective row and column indices in the matrix.

For more details on the Matrix Market format, refer to the official documentation.

# Save sparse counts
counts <- sobj_liver_merged@assays$Nanostring$counts

# Write to format that keeps sparsity in tact
write_out <- writeMM(counts, file.path(out_dir, "Seurat_counts.mtx"))
